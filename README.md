# PrepRank — Flutter / Dart

PrepRank is an exam practice app implemented in Flutter using Dart.

## Features
- Quantitative Aptitude, Logical Reasoning, General Awareness, and English quizzes
- Full mixed mock test
- 60 seconds per question
- Question navigation and clear-answer option
- +1 for a correct answer and -0.25 for a wrong answer
- Results with accuracy, correct/wrong/skipped counts, and explanations
- Best scores saved locally with `shared_preferences`

## Add this source to a Flutter project
1. Install Flutter and create a project: `flutter create preprank`
2. Replace the generated `lib/main.dart` with this repository's `lib/main.dart`.
3. Add `shared_preferences: ^2.3.2` under `dependencies` in `pubspec.yaml` (or use the supplied pubspec dependencies).
4. Run `flutter pub get` and then `flutter run`.

This repository contains the Dart app source and package configuration. Flutter platform folders (Android, iOS, web, etc.) are generated by `flutter create` on a machine with Flutter installed.
